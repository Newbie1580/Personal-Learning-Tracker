# Laboratory Activity #4: Laravel MVC CRUD Application with Migration and Seeder

**Course:** ITE 311 – Web System and Technologies 2
**Topic:** MVC Laravel Framework

---

## Title
Personal Learning Tracker Application

## Objective
At the end of this laboratory activity, the students should be able to:

- Apply the MVC Architecture using Laravel.
- Create and manage database tables using Migrations.
- Populate database records using Seeders.
- Perform CRUD (Create, Read, Update, Delete) Operations.
- Use Models, Controllers, Routes, and Blade Views.
- Demonstrate proper organization of Laravel project files.

## Scenario
Create a simple web application called **Personal Learning Tracker** that allows users to manage learning resources and study progress.

The application is not required to have authentication or advanced features. The primary purpose is to demonstrate Laravel CRUD implementation using MVC Architecture, Migrations, and Seeders.

---

## System Requirements
The application shall allow users to:

### Create
Add new learning resources.

### Read
View all saved learning resources.

### Update
Modify existing learning resource information.

### Delete
Remove learning resources from the database.

---

## Database Requirements
Students must create and implement **at least five (5) migration files** and corresponding models.

## Seeder Requirements
Students must create **at least five (5) seeder files**, one for each table. Each seeder must insert a minimum of:

- Five (5) sample records per table

The database should contain sample data after executing the seeder process.

---

## Required Laravel Components
Students must implement the following:

### Models
Create models for all tables.

### Controllers
Create resource controllers for CRUD operations.

### Routes
Configure routes to handle resource management.

### Views
Create Blade templates for:

- Listing Records
- Creating Records
- Editing Records
- Viewing Record Details

---

## Minimum CRUD Functions
The following modules must support full CRUD operations:

1. Categories
2. Learning Resources
3. Skills

> Note: Only 3 modules are listed, but 5 tables/migrations/seeders are required. Two additional supporting tables are needed.

---

## User Interface Requirements
The application should include:

- Home Page
- Navigation Menu
- Data Table View
- Create Form
- Edit Form
- Delete Confirmation
